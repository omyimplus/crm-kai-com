# Category — ลำดับชั้น (Hierarchy Model)

> **อ้างอิง flow จากลูกค้า:** Client › ประเภทเครื่อง (คอม/โน๊ตบุค) › ยี่ห้อ › สินค้า  
> **Code:** `categories.parent_id` · **UI:** `/app/category` · **สินค้า:** `products.category_id`

---

## สรุปสั้น ๆ

| ชั้นใน flow ลูกค้า | เก็บที่ไหนใน CRM Kai (Phase 1) | ตัวอย่าง |
|-------------------|--------------------------------|----------|
| **Client** | หมวด **ระดับบนสุด** (`parent_id = null`) | ลูกค้าโครงการ · ลูกค้าทั่วไป |
| **คอม / โน๊ตบุค** | หมวด **ระดับ 2** | คอมพิวเตอร์ · โน๊ตบุค |
| **ยี่ห้อ** | หมวด **ระดับ 3** (ใช้ผูกสินค้า) | Dell · HP · Lenovo |
| **สินค้า** | ตาราง **`products`** (ไม่ใช่หมวด) | รหัส SKU · ราคา · หน่วย |

**ลูกค้า (Customer / Company)** เป็นคนละ master กับหมวด — ไม่ใส่ใน tree หมวดหมู่

---

## โครงสร้างตัวอย่าง

```text
[หมวด] ลูกค้าโครงการ          ← Client (root)
  └─ [หมวด] โน๊ตบุค           ← ประเภท
       └─ [หมวด] Dell         ← ยี่ห้อ  ← products.category_id ชี้ที่นี่
            └─ [สินค้า] NB-DELL-7490

[หมวด] ลูกค้าทั่วไป
  └─ [หมวด] คอมพิวเตอร์
       └─ [หมวด] HP
            └─ [สินค้า] PC-HP-800-G9
```

---

## กฎการใช้งาน

1. **สร้างจากบนลงล่าง** — root ก่อน แล้วค่อยสร้างหมวดลูก
2. **สินค้าผูกที่ชั้นยี่ห้อ** (หมวดที่ไม่มีลูก / leaf) — dropdown สินค้าแสดงเฉพาะ leaf + เส้นทางเต็ม
3. **รหัสหมวด (`category_code`)** — สั้น อ่านง่าย เช่น `CLI-ENT`, `NB`, `DELL`
4. **Opportunity / Lead — กลุ่มสินค้า** — ใช้ dropdown หมวดเดียวกัน (แสดง path)

---

## สิ่งที่ระบบทำให้แล้ว

| ฟีเจอร์ | รายละเอียด |
|---------|------------|
| `parent_id` | chain ได้หลายระดับ · กัน loop |
| รายการหมวด | คอลัมน์ **เส้นทาง** แสดง `Client › โน๊ตบุค › Dell` |
| เลือกหมวดแม่ | dropdown แสดง path เต็ม · ไม่ให้เลือกตัวเอง/ลูกเป็นแม่ |
| สินค้า | เลือกได้เฉพาะ **หมวด leaf** (ไม่มีหมวดลูก) |

---

## สิ่งที่ยังไม่แยกตาราง (Phase 1)

| แนวคิด | สถานะ |
|--------|--------|
| ยี่ห้อ (Brand) เป็นตารางแยก | ใช้หมวดแทน |
| Client = ลูกค้าในระบบ | ใช้ **Customer master** · ไม่ใช่ category |
| ประเภทหมวด (enum ชั้นที่ 1–3) | ใช้ **ความลึกจาก parent chain** · ไม่บังคับ field แยก |

---

## คำถามที่ควร confirm กับลูกค้า

1. **Client** หมายถึง **กลุ่มตลาด/กลุ่มลูกค้า** ในหมวด หรือหมายถึง **บริษัทลูกค้า** ใน CRM?
2. หนึ่งสินค้าอยู่ได้ **หนึ่งยี่ห้อ** เท่านั้นหรือไม่? (ปัจจุบัน: `category_id` เดียว)
3. ต้องการ **ยี่ห้อเป็นตาราง master แยก** ใน Phase 2 หรือใช้หมวดต่อไป?
