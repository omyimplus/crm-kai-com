# Frontend KuTo — KC KuTo CRM UI track

> **แยกจาก** `frontend/` (legacy) · **UX อ้างอิง** [Figma Make](https://www.figma.com/make/XZYS22WiMTgEdPInRzwVJS/KC-KuTo-CRM) · **DB** `supabase/` ของ CRM Kai (ไม่ใช้ SQL Figma)

## Dev

```bash
nvm use
cd frontend-kuto
pnpm install
pnpm dev   # http://localhost:3001
```

Copy `.env` จาก `frontend/.env` (Supabase เดียวกัน)
